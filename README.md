# ArchiOS

A personal platform where I document and showcase the things I build, learn, and explore.

I'm currently pursuing:

* B.E. in Civil Engineering at Jadavpur University (2024–2028)
* BS in Data Science and Applications from IIT Madras

This project started because I wanted a single place to keep track of everything I work on instead of having projects scattered across GitHub repositories, folders, drives, notebooks, and CAD files.

---

## What is this?

ArchiOS consists of two parts:

### Admin App

Used to manage everything behind the scenes.

From here I can:

* Add or edit projects
* Upload reports, drawings, datasets, and images
* Manage profile information
* Decide which projects appear publicly
* Review newly detected GitHub repositories

### Public Website

The public-facing side of the platform.

It contains:

* Projects
* Engineering work
* Programming projects
* Data science projects
* Research notes
* Certifications
* Learning journey

---

## Why am I building this?

Most portfolios only show finished work.

I also want to keep track of:

* What I learned
* What mistakes I made
* Different approaches I tried
* How projects evolved over time

Some projects succeed.

Some don't.

Both are worth documenting.

## GitHub Integration

One feature I'm particularly interested in is automatic repository tracking.

When a new repository appears on my GitHub account:

* The platform detects it
* Fetches information about it
* Sends a notification to the admin dashboard

I can then choose whether to publish it on the website.

This keeps the portfolio updated without making everything public automatically.
